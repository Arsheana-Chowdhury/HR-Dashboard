
# 👥 HR Analytics Dashboard | Power BI

## 📌 Project Overview

Developed an interactive Power BI dashboard to analyze workforce demographics, employee status, and employment trends.

## 🎯 Short Description / Purpose

This dashboard aims to provide a clear overview of workforce data and HR performance through interactive visualizations. It helps identify employee trends, understand workforce demographics, and monitor hiring and termination patterns to support informed HR decisions.

## 📊 Key Metrics & Visualizations

- **KPI Cards:** Total Employees, Hired, and Terminated.
- **Country Slicer:** Filters HR data by country and state.
- **Employees by Age Group:** Analyzes workforce age distribution.
- **Educational Status:** Shows employees by education level.
- **Employment Trend:** Tracks hiring trends over time by employment status.
- **Male and Female Employee Status:** Compares active and terminated employees by gender.
- **Active Status by Department:** Compares hired and terminated employees across departments.
- **Top 5 Jobs:** Highlights the most represented job roles.

## ✨ Features / Highlights

- Provides an overview of key workforce metrics.
- Enables country-based data filtering.
- Identifies workforce demographic patterns and employment trends.
- Compares hiring and termination across departments.
- Includes sidebar navigation for dashboard sections and support options.
- Supports data-driven HR planning and workforce management.

## 🛠️ Tech Stack

- Power Query — Data Cleaning and Transformation
- Microsoft Power BI — Data Visualization
- DAX — Calculated Measures
